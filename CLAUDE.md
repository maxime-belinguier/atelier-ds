# Claude Code

Lisez START_HERE.md et AGENTS.md : ce sont les instructions communes du projet.
Le chat Claude intégré passe par `connectors/agents/claude.ts` (sans outils) et
la synchro Figma par `connectors/figma/` (MCP officiel via Claude Code, garde
PreToolUse). Vous pouvez modifier le starter depuis votre terminal avec vos
propres permissions ; une modification ne vaut preuve qu’une fois testée. Pour les tokens, lisez explicitement
`.agents/skills/token-change/SKILL.md`. N’importez aucun cache de compte.
